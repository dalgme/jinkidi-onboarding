# 강사 서류 정리기

강사별 폴더에 흩어져 있는 **이력서 · 통장사본 · 신분증사본**을

1. 모두 **PDF로 변환**하고 (hwp, hwpx, doc, docx, xls, xlsx, ppt, pptx, jpg, png, gif, bmp, tif, webp, heic …)
2. 여러 서류가 한 파일에 묶여 있으면 **서류별로 하나씩 분할**하고
3. **정해진 파일명 패턴**으로 **통합 폴더**에 강사별로 저장하는

로컬 실행 프로그램입니다. **원본 파일은 읽기만 하고 절대 수정·이동·삭제하지 않습니다.**

> 이 도구는 온보딩 허브(Next.js) 앱과 별개인 독립 파이썬 프로그램입니다.

---

## 1. 결과 예시

```
D:\강사서류\                         ← 지정한 원본 폴더 (그대로 유지)
  홍길동\  서류모음.pdf, 이력서.hwp, 통장(농협 2019~2021).jpg
  김철수\  ...

D:\강사서류_통합\                     ← 자동 생성
  홍길동\
    홍길동_이력서_01.pdf
    홍길동_이력서_02_2024.03.05.pdf          ← 한 파일에 묶여 있던 두 번째 버전 (작성일 감지)
    홍길동_통장사본_01_농협은행_2019-2021.pdf ← 은행명·사용기간 자동 표기
    홍길동_통장사본_02_KB국민은행_2022.01-2023.12.pdf
    홍길동_신분증사본_01.pdf
  김철수\ ...
  강사별요약.csv     ← 강사별 서류 개수, 누락 서류, 변환 실패, 검수필요 건수
  검수보고서.csv     ← 만들어진 PDF 한 개당 한 줄 (어느 원본 몇 쪽에서 왔는지)
  페이지분류.csv     ← 원본 페이지 한 장당 한 줄 (수정해서 재생성 가능)
  처리로그.txt
  _작업파일\         ← 변환된 중간 PDF (재생성에 사용, 지워도 무방하나 재생성 불가)
```

## 2. 파일명 패턴

기본: `{강사명}_{서류종류}_{순번 2자리}[_은행명][_사용기간 또는 작성일].pdf`

| 서류 | 예시 |
|---|---|
| 이력서 | `홍길동_이력서_01.pdf`, `홍길동_이력서_02_2024.03.05.pdf` |
| 통장사본 | `홍길동_통장사본_01_KB국민은행_2022.01-2023.12.pdf`, `..._2024.01-현재.pdf` |
| 신분증사본 | `홍길동_신분증사본_01.pdf` |
| 분류 불가 | `홍길동_미분류_01.pdf` (반드시 검수) |

- 순번은 원본 폴더의 파일 이름순 → 파일 안의 페이지 순서대로 매깁니다.
- 사용기간은 **원본 파일명** 또는 본문의 **'사용' 단어 주변**에서만 찾습니다(거래내역 날짜 오인 방지).
- 패턴은 `config.json`의 `filename_pattern`으로 바꿀 수 있습니다.
  사용 가능 값: `{name}` `{doctype}` `{seq}`(`{seq:02d}` 등) `{extra}` `{bank}` `{period}` `{date}` `{today}`
  예) `"{doctype}_{name}_{seq:02d}{extra}"` → `이력서_홍길동_01.pdf`

## 3. 설치 (Windows 기준)

1. **Python 3.10 이상** 설치 (설치 화면에서 *Add python.exe to PATH* 체크)
2. 이 폴더(`instructor-doc-organizer`)를 PC로 복사
3. `run_windows.bat` 더블클릭 → 처음 한 번 필요한 패키지를 설치하고 화면이 뜹니다.

### 형식별로 필요한 프로그램

| 형식 | 필요한 것 (위에서부터 순서대로 시도) |
|---|---|
| PDF, 이미지(jpg/png/gif/bmp/tif/webp) | 추가 설치 불필요 |
| HEIC(아이폰 사진) | `pillow-heif` (requirements 에 포함) |
| doc/docx/xls/xlsx/ppt/pptx | ① PC에 설치된 **MS Office** ② 없으면 **LibreOffice**(무료) |
| hwp/hwpx | ① PC에 설치된 **한컴오피스 한글** ② LibreOffice ③ 그래도 안 되면 텍스트만 추출(서식 손실, 자동으로 '검수필요' 표시) |

- 한글(HWP) 자동화 시 "접근 허용" 보안 창이 뜨면 **[모두 허용]** 을 누르세요.
- 변환 중에는 Word/한글/엑셀을 사용하지 않는 것이 좋습니다(자동화와 충돌).

### 스캔본(사진·스캔 PDF) 글자 인식 — 강력 권장

신분증·통장 사진은 글자가 이미지라서, OCR 이 없으면 **파일명만으로** 분류합니다.
여러 서류를 한 장씩 스캔해 하나로 묶은 PDF 는 OCR 이 있어야 서류별로 나눌 수 있습니다.

- **방법 A (설치 간단)**: Windows 10/11 내장 OCR 사용 → `pip install winocr` (requirements 에 포함).
  한국어 Windows 는 한국어 OCR 이 기본 포함. 영문 Windows 라면 *설정 → 시간 및 언어 → 언어 → 한국어 추가*.
- **방법 B (인식률 좋음)**: [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki) 설치 시
  *Additional language data → Korean* 체크. 기본 경로(`C:\Program Files\Tesseract-OCR`)면 자동 인식.

화면의 **스캔본 글자 인식(OCR)** 을 `자동`으로 두면 Tesseract → Windows OCR 순으로 찾아 씁니다.

### 실행 파일(.exe)

**방법 1 — 빌드된 exe 내려받기 (Python 설치 불필요)**
GitHub 저장소 → *Actions* → **강사 서류 정리기 exe 빌드** → 최근 성공한 실행 → 하단 *Artifacts* 의
`강사서류정리기-windows` 를 내려받아 압축을 풀면 `강사서류정리기.exe` 가 있습니다.
이 워크플로는 Windows 서버에서 테스트 → exe 빌드 → **exe 로 샘플 폴더를 실제 변환·분할**까지 확인한 뒤 올립니다.
`tools/instructor-doc-organizer` 가 바뀔 때마다 자동으로, 또는 *Run workflow* 버튼으로 수동 실행됩니다.

**방법 2 — 내 PC 에서 직접 빌드**: `build_exe.bat` 실행 → `dist\강사서류정리기.exe`

- exe 는 **더블클릭하면 화면**이 뜨고, 인자를 주면 명령줄로 동작합니다
  (예: `강사서류정리기.exe "D:\강사서류" --ocr none`).
- `config.json` 은 exe 와 같은 폴더에 두면 적용됩니다.
- Office/한글/LibreOffice/Tesseract 는 exe 에 포함되지 않습니다. 해당 형식을 변환하려면 그 PC 에 설치되어 있어야 합니다
  (PDF·이미지는 exe 만으로 처리).
- 서명되지 않은 exe 라서 처음 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다 → *추가 정보 → 실행*.

## 4. 사용 방법

1. **원본 폴더**: 강사 이름 폴더들이 들어 있는 상위 폴더를 선택 (예: `D:\강사서류`)
2. **통합 폴더**: 자동으로 `원본폴더_통합` 이 채워집니다. 원하면 변경.
3. **▶ 실행** → 강사 폴더를 하나씩 순서대로 들어가며 변환·분류·분할합니다.
   - 하위 폴더 안의 파일까지 모두 처리합니다.
   - 내용이 완전히 같은 파일(복사본)은 한 번만 처리합니다.
   - 강사 폴더 밖(원본 폴더 바로 아래)의 파일은 처리하지 않고 로그에 알려 줍니다.
4. 끝나면 **요약 보고서 열기** → `누락서류`, `검수필요건수`, `변환실패` 를 확인합니다.

### 검수 후 수정하기 (파일을 하나씩 다시 올릴 필요 없음)

자동 분류가 틀린 경우 `페이지분류.csv` 를 엑셀로 열어 두 열만 고칩니다.

| 열 | 입력값 | 의미 |
|---|---|---|
| 수정분류 | `이력서` / `통장사본` / `신분증사본` / `미분류` / `제외` | 이 페이지의 종류를 강제로 지정 (`제외` = 결과에서 뺌) |
| 수정문서시작 | `Y` / `N` | `Y` 이 페이지부터 새 파일로 분리, `N` 앞 페이지와 같은 파일로 합침 |

저장(CSV 형식 유지) 후 **↻ 보고서 수정 반영 재생성** 을 누르면 변환을 다시 하지 않고 결과 PDF 만 다시 만듭니다.
수정한 값은 보고서에 그대로 남으므로 여러 번 반복해도 됩니다.

> ⚠ 다시 **▶ 실행** 을 누르면 해당 강사 결과와 `페이지분류.csv` 가 새로 만들어져 수정 내용이 사라집니다.

## 5. 자동 분류·분할 원리

- 각 페이지의 글자(스캔본은 OCR)에서 서류별 핵심 단어 점수를 계산합니다.
  - 이력서: 이력서, 인적사항, 학력/경력사항, 강의경력, 자격사항, 프로필 …
  - 통장사본: 통장, 계좌번호, 예금주, 보통예금, 은행 이름, 계좌번호 형식 …
  - 신분증사본: 주민등록증, 운전면허증, 여권, 경찰청장, 구청장, 주민번호 형식 …
- 원본 **파일명**(예: `통장사본.jpg`)도 가산점으로 반영합니다.
- 같은 종류가 연달아 나올 때 나누는 기준
  - 이력서: 페이지 **상단에 제목(이력서/프로필/인적사항)** 이 다시 나오면 새 버전으로 분리, 없으면 이어지는 장
  - 통장사본: **계좌번호가 같으면** 한 파일, 다르면(또는 확인 불가) 페이지마다 분리
  - 신분증사본: 페이지마다 분리 (단, '적성검사/갱신기간' 등 **뒷면**으로 보이면 앞면에 합침)
- 근거가 약하거나 점수가 비슷하면 `검수필요` 로 표시하고, 판단이 안 되면 `미분류` 로 저장합니다.
- 키워드·가중치·분할 방식은 `config.json` 의 `doc_types` 로 조정할 수 있습니다(`config.example.json` 참고).

## 6. 설정 파일

`config.example.json` 을 `config.json` 으로 복사해 프로그램(또는 exe)과 같은 폴더에 두면
**적은 항목만** 기본값을 덮어씁니다. 전체 기본값과 설명은 `doc_organizer/config.py` 에 있습니다.

## 9. 개인정보 주의

신분증·통장 사본은 민감 정보입니다. 이 프로그램은 **인터넷으로 아무것도 전송하지 않으며**(OCR 포함 모두 PC 내부 처리),
결과와 `_작업파일`, 보고서의 `텍스트미리보기` 열에도 개인정보가 담기므로 통합 폴더 보관·공유에 주의하세요.
작업이 끝나면 `_작업파일` 폴더는 삭제해도 됩니다(재생성 기능만 못 쓰게 됨).
